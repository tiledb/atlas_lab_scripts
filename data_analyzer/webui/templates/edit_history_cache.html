Plot Date Range

Limit the X-axis of Production History charts and which milestones appear in the player. Leave start empty to use the earliest relevant date, and leave end empty to use the latest relevant date. Reload Production History after saving; rebuild caches if PNG frames should match the new range.

Rebuild Milestone Caches

Production History stores one cache frame per milestone (brick wall, charts, pies). Rebuilding can take a while; progress is shown in the overlay with a percentage bar. You can also run this from the terminal without starting the web server: python app.py --rebuild-history-cache missing or python app.py --rebuild-history-cache all.
