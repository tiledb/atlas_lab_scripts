Long Burn-In Configuration

Configure the single-board long burn-in period and accelerated aging parameters for the Long Burn In dashboard tab. Telemetry is read from InfluxDB measurement TileBurninTest: environment temperature/humidity and power signals at board level, and FPGA temperatures via tag TileBurninOven <board serial>. The temperature offset is added only to env_temp (environmental aging and env temperature trace). Leave End Time empty to use the current time when plots are loaded.
